# 🌌 1. The High-Level Concept
This is not just a script. It is a **Full-Duplex Conversational AI System**. 
Unlike standard chatbots that wait for you to finish, this system acts like a human:
1.  It **Listens** while speaking (Vosk).
2.  It **Predicts** when you are done (Interaction Engine).
3.  It **Memorizes** what it said (Async Cache).
4.  It **Speaks** with a neural human voice (EdgeTTS).

# 🏗️ 2. Core Components (The Anatomy)

## 🧠 A. The Brain: `src/audio/interaction_engine.py`
**"The Conductor"**
*   **Role:** Manages the State Machine (`IDLE` -> `LISTENING` -> `SPEAKING`).
*   **Key Logic:** `_needs_continuation()`. It decides if you successfully finished a sentence or just paused.
*   **Power:** It stitches "fragmented speech" together. If you say "Explain..." (pause) "...RAM", it merges them.

## 🗣️ B. The Voice: `src/audio/async_engine.py`
**"The Mouth & Memory"**
*   **Role:** Text-to-Speech Streaming & Caching.
*   **Key Technology:** `EdgeTTS` (Microsoft Neural Voice).
*   **The Magic:** **MD5 Caching**. Every sentence is hashed (e.g., `a1b2c...mp3`).
    *   *First time:* Downloads audio (0.5s delay).
    *   *Second time:* Plays instantly from disk (0.0s delay).
*   **Streaming:** It downloads Sentence 2 while playing Sentence 1. Zero gaps.

## 👂 C. The Ears: `src/audio/vosk_detector.py` & `whisper_transcriber.py`
**"The Reflex & The Scribe"**
*   **Vosk (`vosk_detector.py`):** 
    *   *Role:* The "Reflex". Always running. Low accuracy, High speed.
    *   *Job:* Detects **Interrupts**. If it hears > 4 characters, it screams "STOP!" to the engine.
    *   *Smart Logic:* Ignores "Okay", "Uh-huh" (Backchanneling).
*   **Whisper (`whisper_transcriber.py`):** 
    *   *Role:* The "Scribe". Runs only when you stop speaking.
    *   *Job:* Converts audio to perfect text using Google Speech API (fallback) or local Whisper.

## 🤖 D. The Body: `main_gemini.py`
**"The Loop"**
*   The entry point. It initializes `GeminiAudioController` and runs the infinite `while True` loop.

# 🌊 3. The Data Flow (Step-by-Step)

## Scenario: You ask "Explain Binary Files"

### Phase 1: Listening 👂
1.  **Start:** `main_gemini.py` calls `controller.listen()`.
2.  **Engine:** `InteractionEngine` enters `LISTENING` state.
3.  **Transcriber:** `WhisperTranscriber` opens the mic.
4.  **User Speaks:** "Explain binary files..."
5.  **Smart Wait:** You pause. The Engine checks `_needs_continuation("Explain binary files")`. It sees it's a complete thought.
6.  **Result:** Returns `"Explain binary files"` to the Router.

### Phase 2: Thinking 🤔
1.  **Router:** `EnterpriseQueryRouter` takes the text.
2.  **Search:** It searches ChromaDB (Vector Store) for "binary files".
3.  **LLM:** It prompts Ollama/Gemini: "User wants to know about binary files. Keep it concise."
4.  **Output:** LLM returns: *"Binary files store raw bytes..."*

### Phase 3: Speaking & Streaming 🗣️
1.  **Command:** `controller.speak("Binary files store raw bytes...")`
2.  **Clean:** `AsyncEngine._clean()` strips hashtags `###` and emojis `✨`.
3.  **Split:** Text is split into sentences: `["Binary files store raw bytes.", "They are fast."]`
4.  **Pipeline (Parallel):**
    *   **Sentence 1:** Checks `cache/hash1.mp3`. Missing? Download -> Play.
    *   **Sentence 2:** Checks `cache/hash2.mp3`. Missing? Download (Background) -> Queue.
    *   **Sentence 1 Ends:** Sentence 2 is *already ready*. Plays instantly.

### Phase 4: The Interrupt (Barge-In) 🛑
1.  **State:** System is speaking Sentence 2.
2.  **User:** "Wait, stop!"
3.  **Vosk:** Background thread hears "Wait, stop".
4.  **Check:** Is it "Okay"? No. Is it len > 4? Yes.
5.  **Action:** `audio_engine.stop()`. Clears queue. Kills audio.
6.  **Event:** `InteractionEngine` transitions to `INTERRUPTED`.
7.  **Recovery:** System immediately goes back to `LISTENING` to hear your objection.

# 🚀 6. Why This is "Advanced"
1.  **Asynchronous I/O:** It uses Python `threading` and `queue` to do 3 things at once (Listen, Download, Play).
2.  **Caching Strategy:** It solves the "Slow Cloud TTS" problem by saving every unique sentence forever.
3.  **Robustness:** It handles Internet failures (will fail to generating new audio but keep playing old) and Mic failures (restarts stream).
4.  **Math Core:** The `DeepBrain` module proves we can do analytics without heavy dependencies.

This is a **Production-Grade Conversational Architecture** running on your local machine.
