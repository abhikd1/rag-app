---

### Step 2: Query with MODE A

#### Method 1: Automatic Detection (Page Queries)
Just ask for a page number:
```
Page 14
```
```
What is on page 20?
```
```
Show me page 13
```

#### Method 2: Explicit Mode Selection
Start your query with `MODE: A`
```
MODE: A
What does the book say about transformers?
```

#### Method 3: Exact Recall Keywords
Use these phrases:
```
Give me the exact text about GPT-2
```
```
Word for word, what is written about attention mechanism?
```
```
Verbatim text from page 25
```

#### Method 4: MODE B (Stuck-Point Explanation)
If you find a specific sentence or concept confusing, use:
```
MODE: B
I am confused about the "thought vector" on page 20.
```
```
Explain this part: "it could solve most of them" on page 14.
```

---

## 🎯 WHAT THE MODES DO

### 📄 MODE A: EXACT RECALL
✅ Returns EXACT text from the book
✅ Preserves original paragraph structure
✅ NO summaries or explanations (unless you ask)

### 🧩 MODE B: STUCK-POINT EXPLANATION
✅ Explains ONLY the specific part you're stuck on
✅ Uses context from the book to clarify
✅ Connects the explanation back to the original text
